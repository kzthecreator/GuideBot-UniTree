## 结论
声学处理代码与选定历史基线一致。
没有发现最近导览修改改变对话AEC、AGC或确认打断门槛。
这不等于现场声场或云端模型行为相同，也不证明效果没有退化。
本次未调整运行参数。

## 本轮失败表现
5次候选中，2次判为backchannel，0次确认打断。
一次输入提交后的最终转写为空。
另一次为正常开场“你好”，最后一个候选在结束前没有结论。

录音文件14至15秒：原始RMS -31.50dBFS。
LocalVQE后为-93.52dBFS，AGC后-91.01dBFS。
这证明显著衰减发生在LocalVQE内。
但该窗口没有人工区分用户人声和机器人回声，不能直接宣称误消除了用户声音。
历史11月17日报告已有用户确认的同类误抑制，未被彻底解决。
参见docs/experiments/normal-speech-20261117.md。

## 生命周期异常的边界
当前结果包含ROS心跳丢失和worker停止超时。
ROS日志也记录了用户Ctrl+C退出，尚不能断言是运行中故障造成的退出。
1.16秒回调阻塞按observed_at回推发生于启动附近。
它不是结尾日志写入时才发生，不能据此解释此前全部漏打断。
