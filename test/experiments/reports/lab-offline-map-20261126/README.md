## 为什么没直接使用二维ICP

先试二维投影匹配，局部重合率很高但闭环失败（末帧离起点约8.08m）。改用三维对应点、平面运动拟合仍失败（约9.54m），因为0.3秒采样间隔中转角最大36.72°，从前帧零转角初值容易收敛到错误方向。保留三维对应点，以同源时间插值的原厂odom相对转角作为初值后，真实点云匹配给出了闭环一致结果。没有使用原厂odom平移叠加地图，没有假定雷达到robot_center是identity TF。

当前算法使用测得的地面校平，离地0.3–1.7m、半径0.5–12m障碍点，8cm体素，前8帧局部地图，0.4/0.2/0.1m三级最近点ICP。闭环搜索初值利用用户回到起点的事实，朝向则取原厂相对转角；不是全局回环检测。草稿指标阈值见`docs/lab-mapping.md`。
